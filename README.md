## 从调研到方案

19题问卷回收159份，排除8份硬性质控问题，另41份经进一步筛选未纳入，最终保留110份。30条公开反馈（正向、负向各15条）补充使用场景，iOS 9.6.15的截图和操作经过用于核对具体缺口。

- 51/110人选择“广告、弹窗或活动提示影响使用”（46.4%），相关体验均分2.50/5。
- 37/110人选择页面信息或入口问题（33.6%）。搜索、个人音乐管理、个性化推荐分别被109、72、64人列为主要使用功能。
- 问卷提示关注方向；作品参与关联、推广展示和举报查询的具体范围通过个案及现有能力核对确定。
- 选择时综合**问题严重程度、证据强度、影响范围和实施依赖**。版权采购、复杂跨端同步等保留在需求池，等待进一步确认资源与依赖。

## 三个方案方向

| 方案 | 具体设计 | 验证重点 |
| --- | --- | --- |
| 歌手作品完整浏览与整理 / P1配套建议 | 保留Various Artists合集署名，核对参与角色，补齐艺人—专辑关联，刷新现有列表；冲突项转内容复核 | 已确认参与的合集可从艺人主页找到，版本与参与范围准确，误关联可纠正 |
| 听歌流程推广干扰控制 / P1重点体验方案 | 先判断任务、权益、关闭和频次，再匹配内容与形式；保护音乐信息及关键入口，取消失去时机的请求 | 任务完成、耗时、误触、拒绝生效、有效转化及每次使用收益共同评估 |
| 评论及陌生互动举报反馈 / P0基础保障 | 受理后持续可查，区分真实处理状态；所有结案结果说明原因，保留个人屏蔽及适用后续选择 | 受理成功、进度可见、结案覆盖、通知与记录一致、即时退出和屏蔽 |

## 竞品如何影响设计

- **作品关联：** Spotify的合集与Appears On、TuneCore Japan的参加作品支持“保留合集署名，同时关联参与艺人”。
- **推广：** QQ音乐的个性化设置、Spotify的广告偏好及广告组频控，帮助区分内容匹配、拒绝和曝光控制。本方案增加跨页面共享打扰规则，并保障个性化布局中的基础入口。
- **举报：** Spotify的互动控制和举报说明、YouTube举报历史用于比较退出、状态、结果解释与查询覆盖。

竞品依据截至2026-11-01核对的官方材料；地区、版本及广告产品范围分别说明，移动端任务实测列入验证计划。原始来源见[竞品分析](docs/zh/competitive-analysis.md)。

## 交付状态与数据边界

四份文档及流程、概念页面、效果指标、验收要求已完成。下一步为技术评审、原型任务测试、基线记录和小范围灰度。推广控制为重点体验方案，举报反馈的P0表示安全与信任基础要求。

18—30岁用户占91.8%，学生占75.5%；关系网络与转发招募限制样本代表性。公开反馈与操作记录用于定性核对。关联分析使用3,000次置换检验及34项检验的BH FDR校正，报告Cramer’s V与η²_H；广告与自报变化的关联在校正后未达显著，留存及收入收益通过后续实验验证。
